# 商品研究日历

从电力、动力煤、甲醇和原油切入，按时间追踪事件怎样改变供需、成本与市场结果。宏观和气候事件只保留一份，各品种分别维护影响路径、观测指标与成立条件。

[打开 Excel](./outputs/商品研究日历.xlsx) · [结构化数据](./data/catalog.json)

## 怎样使用

在季度总览选择年份、品种和地区。季度采用自然季度，Q1为1—3月，Q2为4—6月，Q3为7—9月，Q4为10—12月；气象季节、供暖季与丰枯水期写在研究维度的时间窗口中。仅有年度安排的项目进入年内待定，不分配虚构的季度。

新增事件时，在共享事件填写事实、时间、状态和来源。在品种影响中，通过同一事件ID关联电力、甲醇、原油或动力煤，并分别填写影响判断。一条事件可以对应多条品种影响，也可以同时影响一个品种的供给和需求。修改共享事件后，已有影响行与季度总览随公式更新。影响判断属于研究解释，事件事实以对应来源为准。

地区选全部可查看全部已录入影响。选择具体地区时，同时显示全球、全国及该地区的记录；全国记录提供背景，数值不自动赋给该省。当前样例用于检验研究结构，各年覆盖并不完整；空白季度表示尚未录入。

Excel中浅黄色区域可编辑，绿色区域为关联公式。事件ID和影响ID用于关联，创建后保持稳定。当前文件为常用编辑区预留至第301行，超出时需扩展公式与筛选范围。季度总览使用FILTER和TEXTJOIN，需要支持动态数组的Excel版本。源表始终可筛选和直接编辑。

## 电力研究的五组变量

| 模块 | 首批内容 | 需要保留的差异 |
| --- | --- | --- |
| 供给 | 煤电、气电、风电、光伏、核电、水电、光热及其他电源 | 装机、可用功率与上网电量分开 |
| 需求 | 工业、居民制冷采暖、服务业、农业、充换电、数据中心、日历 | 潜在用电需求与受限后的实际负荷分开 |
| 输电与调节 | 省间交换、网内断面、电化学储能、抽水蓄能、需求响应 | 电力的地区、时段与网络边界 |
| 制度与价格 | 中长期、日前、实时、价格边界、容量及辅助服务、碳和绿证 | 电能量价格、发电收入与终端电费分开 |
| 宏观与气候 | 经济、利率汇率、地缘贸易、ENSO、复合极端天气 | 共同事件下的品种弹性、时滞与方向差异 |

辽宁先关注徐大堡各机组进度、核电检修、供热机组约束及风光变化。甘肃先关注风光资源与装机、外送兑现、调节能力及工业新负荷。省份作为同一体系内的地区字段，继续新增省份时复用共同维度。

原油与甲醇的关联要区分生产路线。煤和天然气是传统甲醇的重要原料，原油主要经石脑油裂解、烯烃路线竞争和燃料替代传导。原料煤与电煤的煤质、热值及用途也需要分别定义。[IRENA甲醇报告](https://methanol.org/wp-content/uploads/2020/04/IRENA_Innovation_Renewable_Methanol_2021.pdf)、[Methanol Institute MTO介绍](https://methanol.org/what-chemicals-mto)

## 事件与数据口径

徐大堡3号和4号分别跟踪。当前录入的公开年度安排为2027年和2028年建成，首次并网和商运另设节点。热试、送出工程送电、许可前检查均为各自已经发生的工程节点，不能直接记成新增发电量。[辽宁省发展改革委](https://fgw.ln.gov.cn/fgw/zfxxgk/fdzdgknr/jyta/szxta/szxssjschy2025n/2025120317225483462/index.shtml)

[PowerCurve气象数据](https://powercurve.cn/#weather)可按省查看ERA5月报，并提供趋势和季节入口。首条风速样例使用全国100米月均风速及相对1995—2024同月基准的标准化距平。距平与同比分开存储：同比为本年同月值除以上年同月值再减1；标准化距平为当前值与历史同月均值之差除以同月标准差。上年同月为零或缺失时不计算同比。

后续接入辽宁、甘肃月度序列时，指标至少包含地区、年月、变量、单位、风速高度、统计方法、数据来源及基准期。风速按小时u/v分量合成标量后再求平均，保留省级空间聚合口径；风速变化与发电量变化还受到装机、功率曲线和限电影响。气温用摄氏度差值或距平比较，不以摄氏度同比解释冷暖。

## 从 Excel 到数据库和网页

`data/catalog.json`包含四类记录，保持稳定ID：

| 数据对象 | 主键 | 关系与用途 |
| --- | --- | --- |
| events | id | 事件事实、时间精度、状态、来源 |
| impacts | id | 通过event_id关联事件，记录品种、地区和机制 |
| factors | id | 可复用研究维度、指标、季节窗口与边界 |
| relations | id | 有方向的品种关系，保留中间环节和适用条件 |

网站可以从品种、地区、年份三个筛选器进入季度日历，点击事件打开侧栏。在侧栏修改共享事实，在品种页修改该品种的影响判断；保存前显示受影响的关联记录。关系图负责跳转到相邻品种，并保留年份和地区筛选。事实、判断和观测序列分别展示，避免一条宏观消息被复制成多份互不一致的记录。

下一阶段增加指标序列表和独立来源表，事件通过关联表引用多个来源。正式数据库采用关系表即可承载这些多对多关系，无需先引入图数据库。多人在线编辑还需要登录权限、修订历史和并发冲突处理；当前GitHub通过分支和Pull Request协作，Excel本地修改不会自动同步到GitHub。

## 维护数据

Excel和结构化数据通过显式导入保持一致。日常修改在Excel完成后运行：

```powershell
python scripts/import_workbook.py outputs/商品研究日历.xlsx
```

脚本只读取四个输入页，校验ID和关联，忽略公式列；结构化数据已被其他修改更新时会停止，避免用旧Excel覆盖新内容。审核差异后一起提交工作簿和结构化数据。新克隆的仓库先运行同一命令的`--check`，建立内容一致的编辑基线。

公开协作提交新写的事实摘要、机制判断和可公开的来源链接。第三方原文与数据使用权仍归原权利人；完整历史工作表、付费数据库和内部工作资料不作为公开数据提交。
