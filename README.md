# 事件数据库

[打开网页](https://xuelixunhua.github.io/commodity-research-calendar/)

我们希望共同建设一个可以长期积累、相互验证的事件数据库：把重要变化、原始证据与产业联系放在一起，让分散的观察逐渐形成对行业的理解。

目前重点建设**电力及其与煤炭的联动**，从全国气象资源、全国与分省装机、分电源发电量、煤炭供需和价格中寻找值得记录的变化。项目也保留原油、甲醇、LPG 等历史研究，未来希望逐步覆盖更多行业、公司与股票。

我们关心变量什么时候改变、变化有多大，以及它如何传递到其他行业。一次低风、水电丰发或新能源装机跃升，既是电力事件，也可能改变火电发电和耗煤需求。同一事实只维护一份，在相关研究对象中共同引用，保留一致的指标、时间、单位和来源。

**欢迎一起补充。** 无论是提供一条有出处的事件、修正一项数据、补充产业链联系，还是用后续数据检验已有判断，都能让这个数据库更有价值。熟悉电力、煤炭或其他行业的研究者，以及愿意改善数据与页面的开发者，都可以参与；不需要先掌握项目代码。

[研究方法与协作规范](docs/研究方法与协作规范.md) · [参与补充](CONTRIBUTING.md)

可以通过 [Issue](https://github.com/xuelixunhua/commodity-research-calendar/issues/new/choose) 提供事实与来源，或提交 Pull Request。尚待验证的解释也欢迎讨论，事实与判断分别表达。

## 浏览与使用

按研究对象、供给、需求、数据和宏观因素浏览季度事件；年度判断跨全年展示。拖动年份滑块选择区间，点击年份可多选；各年独立展示四个季度，底部滚动条切换查看。

点击事件查看来源和影响，点击因素回看全部历史。“产业链”区分供需流向、成本与反馈、跨品种联系；点击节点查看机制、指标和适用条件。网页支持新增、编辑和本地草稿；通过“数据管理”导出 JSON，上传替换 `data/catalog.json`，提交更改或 Pull Request。合并到 `main` 后自动发布。

本地预览：`python -m http.server 8765`。数据校验：`npm test`。
