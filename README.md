# 事件数据库

[打开网页](https://xuelixunhua.github.io/commodity-research-calendar/)

记录产业变量怎样变化、经过什么机制影响市场，以及判断何时得到验证。当前覆盖电力、原油、甲醇、动力煤、LPG 和宏观；后续可扩展公司、股票与其他行业。

[研究方法与协作规范](docs/研究方法与协作规范.md) · [参与补充](CONTRIBUTING.md)

按品种、供给、需求、数据和宏观因素浏览季度事件；年度判断跨全年展示，季度主线与各因素分别展开。同一事实可关联多个品种，并分别记录影响与关注程度。拖动年份滑块选择区间，点击年份可多选；各年独立展示四个季度，底部滚动条切换查看。

点击事件查看来源和影响，点击因素回看全部历史。“产业链”区分供需流向、成本与反馈、跨品种联系；点击节点查看机制、指标和适用条件。网页支持新增、编辑和本地草稿；通过“数据管理”导出 JSON，上传替换 `data/catalog.json`，提交更改或 Pull Request。合并到 `main` 后自动发布。

本地预览：`python -m http.server 8765`。数据校验：`npm test`。
