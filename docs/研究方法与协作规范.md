# 事件数据库：研究什么，记录什么

事件数据库保存市场运行方式发生变化的证据，以及研究者在当时信息下作出的判断。读完某一季度，应能回答：主要矛盾在哪里，哪项变化推动了它，价格和利润如何响应，原有判断在哪一步得到验证或需要修正。

项目当前重点建设电力及其与煤炭的联动，同时保留原油、甲醇、LPG 的历史研究。未来逐步扩展到股票、公司和其他行业；愿景与参与入口见[项目首页](../README.md)。

## 一、从历史记录中保留的研究方法

历史日历同时保存年度判断、季度主线和供需因素。这三个尺度相互约束：年度判断给出产业背景，季度主线识别当期矛盾，因素记录提供支持或反驳判断的证据。

| 历史记录中的做法 | 它解决的问题 | 继续维护时应保留什么 |
|---|---|---|
| 原油按 OPEC、俄罗斯、美国产量及不同油品需求拆分 | 总量变化来自哪里，油种和区域结构是否错配 | 宣布与执行、实际供应、油品需求和库存各自的变化 |
| 甲醇同时记录进口、煤制利润、MTO 利润和开工 | 上游成本变化如何穿过利润约束，最终改变供需 | 原料成本 → 上游利润 → 开工，以及甲醇价格 → 外采 MTO 利润 → 采购的双向反馈 |
| LPG 将 PDH 利润与开工并列，并跟踪港口库存 | 新增产能能否形成实际原料需求 | 投产、进料、负荷和库存消耗的先后顺序 |
| 同一因素连续记录低位、回升、超预期和兑现 | 变量的水平、变化和市场认识是否同步 | 同比、环比、季节位置、预期基线与验证时间 |
| 每季写核心逻辑 | 哪个因素在当前约束下最有解释力 | 主矛盾、关键证据、竞争解释和下一验证点 |

例如，2024 年 Q2 甲醇记录把进口偏紧、港口压力与外采 MTO 停车放在同一季度。可复用的认识是供给收缩可能通过涨价压缩下游利润，进而触发需求收缩。具体历史表述仍保留为当期研究记录，其确定程度需要相应来源支撑。

季度判断可以随证据更新，但当时的预期与后来得到的结果应分别保留。事后看到价格上涨，不能补写成事前已经判断正确。

## 二、一条值得保存的记录

先提炼少数改变市场运行方式或主要供需约束的关键变化，按影响的重要性组织记录。材料中的主题数量不决定事件数量；常规波动、解释性数据和案例细节作为事件的依据，显著转折再单独入历。

### 事件录入要点

- **先选关键变化。** 优先记录价格边界、交易资格、收入保障、结算与费用分摊，以及有效供给和需求约束的改变；判断其规模、持续性及对当前主要矛盾的影响。
- **一句话说清事件。** 标题和首句交代地区、发生时间与变化内容，详情再解释它如何影响报价、供需、利润或结算。核验细节不能冲淡主结论。
- **时间对应业务环节。** 政策发布、生效、首次结算、费用体现分别核对；以本条事件关注的实际环节定位日历。只有月份依据时保留月份，不补造具体日期；追溯结算保留费用所属期与体现期的区别。
- **证据围绕事件补齐。** 正式文件支持规则内容，运行数据与账单支持执行结果；分享材料支持的观察保留其来源边界。气象、检修、价格等数据用于解释和验证，达到显著转折时再形成独立事件。同一事实复用已有记录并关联受影响对象。

例如，辽宁2026年的制度变化可收束为三项：1月现货出清下限降至−100元/MWh、1月新能源机制电价开始执行、4月核电机制费用开始体现。核电文件自1月1日起实施与4月费用体现分别表达，不能用一个日期代替两个环节。

记录首先确定研究对象、地区、时间和变量，再依次回答以下问题：

1. **发生了什么变化？** 给出量级、单位、基线及来源。事件、统计观察、研究预期各自标明性质。
2. **改变了哪条关系？** 落到产量、可用供应、采购、利润、库存、结算或风险约束，说明受影响对象。
3. **为什么值得关注？** 判断变化的规模、持续时间、替代难度及是否触及当前瓶颈。行业总量中的占比通常比孤立绝对值更有解释力。
4. **影响在什么时候发生？** 区分公告、执行、物理兑现和收入确认；记录运输、检修、投产爬坡、订单交付等滞后。
5. **怎样验证或推翻？** 指定可观察指标、复核窗口、竞争解释和失效条件。价格结果只是验证的一部分。

同一事实只保存一次，各对象分别记录影响。例如煤价上涨可以抬高煤电边际燃料成本、压缩煤制甲醇利润，也可能改善部分煤企盈利；方向取决于采购结构、合同和售价传导。

### 入历的三类变化

| 类型 | 典型内容 | 合格证据 |
|---|---|---|
| 离散事件 | 政策生效、实际投产、停运、航线中断、订单签订 | 对象、执行时间、影响规模、原始公告或独立观测 |
| 状态转变 | 利润转负、持续去库转累库、风资源持续偏弱、水电增发 | 同口径连续数据、对照基线、持续性；排除缺失或统计修订 |
| 预期差与反馈 | 减产兑现低于预期、到港超预期、亏损导致降负、风险解除 | 当时可获得的预期及其时间戳、后续实际、偏差规模 |

阈值用于发现候选。跨过阈值之后，还要判断它是否改变了研究对象的约束。同一事件的连续报道合并更新；原因相同的一轮行情可形成一条阶段记录，并在详情中保留过程。平常月份的基础数据留在数据源，具有比较价值的观察可以作为一般记录。

历史分位只在足够长、可比的样本内使用。新装机、制度变化和样本扩张会改变分布；季节性变量先与同季节比较。没有同时期预期数据时，使用同比、环比或计划差，避免写成超市场预期。

## 三、电力与煤炭共同研究一条供需链

当前重点是气象资源、发电能力和实际发电量的显著变化。研究沿着以下关系展开：

**风、光、水资源与装机 → 实际非化石发电量 → 在用电需求和外送条件下的火电发电量 → 电厂耗煤、采购与库存 → 煤炭供需和价格。**

煤炭生产、进口、运输和库存又影响电厂燃料供应与采购成本。这些关系存在时滞，也受长协、调度和供需约束影响；不能由单个气象或装机指标直接推出煤价方向。

### 当前优先补充的四组事实

| 事实 | 什么变化值得记录 | 怎样验证电煤联动 |
|---|---|---|
| 全国与重点地区风、光、水资源 | 同月历史样本中的明显高低值、持续低风低辐射、异常来水 | 先核实际风光水电量，再看火电量和日耗；全国平均与装机集中地区并看 |
| 全国与分省装机 | 真实跨过重要量级，月度净增或增速显著，电源结构改变 | 装机是否形成有效出力，增量是否被需求增长吸收，是否影响当地或受端耗煤 |
| 分电源发电量 | 水电明显丰发或偏枯、风光电量偏离资源表现、火电增减发生转折 | 同期用电量、风光核水电、跨区送受电共同解释火电变化 |
| 煤炭供需与价格 | 电厂日耗、补库、库存、生产进口和基准煤价的阶段变化 | 区分需求拉动、供给收缩和补库行为，检验前述电力变化是否实际传导 |

### 一份事实，多个研究入口

水电增长这条记录在电力页解释发电结构，在动力煤页解释耗煤需求。标题、数值、时间、来源与指标定义来自同一个事件，补证和纠错同时生效。影响可以因研究对象而不同，但不重新编写另一份事实。

煤价也遵循同样原则。当前港口基准为**秦皇岛山西产5500大卡动力煤平仓价，元/吨**；它既供电力成本研究使用，也供动力煤和煤化工研究使用。产地价、进口到岸价、到厂价、长协价分别保存，不能混为全国均价。天气偏弱也不是煤价上涨的充分条件，煤炭供给和库存可能抵消需求变化。

### 已有记录举例

| 变化 | 共用事实及来源 | 下一步验证 |
|---|---|---|
| 2026年3月全国平均百米风速偏低 | [PowerCurve](https://powercurve.cn/#weather)的ERA5月度序列：相对1995—2024年同月均值偏低8.3%，在本月与30个历史同月样本中由低到高排第2位 | 主要风电地区是否同样偏弱，风电发电量是否受到影响，火电和日耗如何响应 |
| 2025年5月全国太阳能装机跨过10亿千瓦 | [国家能源局](https://www.nea.gov.cn/20250623/6a557ee5ad944062a6c01d6e8417474e/c.html)披露月末装机108445万千瓦；较[4月](https://www.nea.gov.cn/20250522/ba33708cb5e749378a21c955170069c1/c.html)净增9240万千瓦 | 随后发电量、利用率和需求增量，不能直接把装机净增折算为实际节煤 |
| 2025年5月内蒙古新能源装机突破1.4亿千瓦 | [自治区政府披露](https://www.nmg.gov.cn/zwyw/jrgz/202506/t20250616_2740105.html)：14309万千瓦，占全区装机52% | 省内消纳与外送分别影响哪里的火电和耗煤 |
| 2025年9月水电转强、火电下降 | [国家统计局](https://www.stats.gov.cn/sj/zxfb/202510/t20251020_1961605.html)可比口径：水电同比增长31.9%，火电下降5.4% | 核对用电增长、其他电源、日耗与库存，检验水电替代的作用范围 |

PowerCurve当前全国月度指标是33个区域等权平均，使用ERA5再分析数据；蒙东、蒙西分别列示。它不是全国装机加权资源，也不是实际发电量。现有地表太阳辐射以W/m²表示，不能改称倾斜面总辐照GTI。后续接入GTI时须单独明确倾角、方位、时间累计和单位。

## 四、从数据中筛选并验证

阈值用于找出值得研究的候选，入历前还要检查来源、比较口径和实际影响。同一期的多个触发合成一条事件，连续变化保留阶段联系。

| 类型 | 筛选方法 | 关键边界 |
|---|---|---|
| 气象异常 | 与固定气候基准的同月样本比较，优先检查上下10%范围；说明偏离幅度和持续性 | 当前基准1995—2024年，至少30个同月样本；重新对全国聚合序列计算，不把各地区标准化值均值当全国标准化值 |
| 装机突破 | 按电源规模设置固定量级；有连续前值证明跨越，或公开原文明确确认 | 全国、全省和电网经营区分开；全口径与6000千瓦及以上分开；估算和插值不确认突破 |
| 装机加速 | 变化率与绝对净增同时达标，再检查同比和季节集中投产 | 相邻月末存量差称净增；没有相邻真实值时不制造月增速 |
| 发电量异常 | 同期位置、同比增速、绝对增量与电源结构结合；丰枯季分别比较 | 使用官方可比同比；规上统计范围会变化，不能拿两年已公布量相除冒充官方同比；1—2月合计不拆造单月 |
| 电煤响应 | 比较火电、煤电、日耗、补库和库存，再对照同口径煤价 | 火电不全是煤电，采购不等于消耗；相关性和同期变化不足以证明因果 |

先明确预期传导与观察窗口，再查看结果。支持、未兑现、被其他因素抵消和证据不足，都可以作为验证结论。数据源提供日常序列，事件数据库保留值得解释的变化和后续证据。

## 五、扩展到股票与其他行业

扩展以研究对象和现金流机制为中心。股票需要区分行业、公司、证券和业务分部；一家公司的某项业务受益，不自动意味着所有证券在同一窗口上涨。

| 商品研究中的问题 | 股票或其他行业的对应问题 | 必要边界 |
|---|---|---|
| 产能、开工、产量 | 资本开支、投产爬坡、交付与收入确认 | 宣布投资、签约、验收和确认收入分别记录 |
| 成本、加工利润 | 原材料成本、产品售价、毛利率与现金流 | 产品结构、合同调价和库存成本会造成滞后 |
| 库存与采购 | 库存周转、渠道库存、订单和应收款 | 框架协议、在手订单和可收回现金不等量 |
| 供需预期差 | 业绩指引、盈利预期和实际财报 | 必须保存预测来源及当时版本，避免事后选择基线 |
| 品种间传导 | 上下游客户、供应商与替代技术 | 同一变化可能改善上游利润并压缩下游利润 |

共同数据结构继续采用事实、对象影响、研究因素与产业联系。当前页面以品种为入口；公司和证券需要稳定代码、市场与业务关系后再扩展。暂不创建没有数据的股票空壳，也不把股票代码直接写进商品名称充当完整公司模型。

## 六、怎样共同补充

贡献可以是新事件、已有记录的原始来源、竞争解释、验证结果或产业链关系修正。增加记录数量不是单独的质量目标。

一条贡献至少包含：对象与地区、事实归属期、公开来源及发布日期、明确变化、影响机制、比较口径、验证指标和条件。若是预期，补充形成时间与兑现窗口；若是纠错，指出原记录及变化依据。

事实采用可复核来源；正式文件、统计观测、研究观点和传闻分别处理。来源存在冲突时保留差异和适用范围。模型估算与插值须标明，不能伪装为正式披露。私有持仓、客户信息、登录资料、内部路径和无传播授权的原始数据不进入公开仓库。

在页面编辑后，可导出完整 JSON，提交修改或 Pull Request；也可以通过 Issue 提供事实和来源，由维护者关联到对应因素。提交前运行 `npm test`，并检查新记录在对应年份、季度和对象中能被找到。数据结构说明和提交入口见 [贡献指南](../CONTRIBUTING.md)。

研究方法随事实、案例和复盘修正。值得保留的进步包括识别出更重要的变量、缩短验证链、纠正错误归因，以及明确哪些问题当前证据仍回答不了。
